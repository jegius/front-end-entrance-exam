# Описание проекта
Мой проект - сервис, позволяющий создавать собственное резюме на основе шаблона.
При нажатии на кнопку "редактировать" красным цветом выделяются все области, в которых можно поменять текст.
Чтобы применить изменения, необходимо нажать на кнопку "редактировать" ещё раз.
Кнопка "стереть" приводит весь в начальное состояние, а кнопка "сохранить в PDF" даёт скачать резюме в формате PDF.
