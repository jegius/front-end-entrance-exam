Добро пожаловать в мой проект!!!


Как установить:

1. переходим в нужную ветку - git checkout develop
2. устанавливаем зависимости npm i
3. запускаем проект npm run dev


Сразу скажу: на сайте есть музыка! Если нужна тишина, лучше перед запуском выключить динамик. А если же нет, то наслаждайтесь^^

Использовал компонентый подход - все функции импортировал в main.js, из него обращался к div с #app у файла index.html

Чтобы узнать все функции, которые я реализовал, при запуске приложения нажми на кнопку "Нажать перед работой с сайтом" и всё будет понятно.

Приятного пользования!!!
