🧪 Front-End Вступительный Экзамен — Интерактивное Резюме

✨ Проект представляет собой адаптивное и редактируемое резюме с ripple-анимацией в стиле Material Design и возможностью экспорта в PDF.

⸻

🔥 Возможности
• 📝 Редактирование в реальном времени — просто кликайте по тексту, чтобы изменить его
• 📄 Экспорт в PDF — сохраняет весь стиль и структуру через [html2pdf.js](https://github.com/eKoopmans/html2pdf.js)
• 💧 Ripple-эффект — реализация анимации нажатия по стандартам Material Design
• 📱 Адаптивный дизайн — оптимальное отображение на телефонах, планшетах и десктопах
• ⚡ Мгновенный запуск — минимальная конфигурация благодаря Vite

⸻

🛠️ Технологии
• Vite — быстрый сборщик с HMR
• Vanilla JavaScript — без фреймворков, чистый код
• CSS3 — Flexbox, Grid, анимации и адаптив
• HTML5 — семантическая и валидная разметка
• [html2pdf.js](https://github.com/eKoopmans/html2pdf.js) — генерация PDF-документов прямо из браузера

⸻

🚀 Быстрый старт

1. Установка зависимостей

```bash
npm install
```

# или

```bash
yarn install
```

2. Запуск в режиме разработки

```bash
npm run dev
```

# или

```bash
yarn dev
```

3. Сборка для production

```bash
npm run build
```

# или

```bash
yarn build
```

4. Просмотр production-сборки

```bash
npm run preview
```

# или

```bash
yarn preview
```
